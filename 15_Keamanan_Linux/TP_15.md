## Dasar Teori
Shell Scripting atau Bash Scripting pada sistem operasi Linux adalah sebuah program berupa kumpulan perintah CLI (Command Line Interface) yang disimpan di dalam satu berkas teks (biasanya berekstensi .sh) untuk dieksekusi secara berurutan oleh shell interpreter. Manfaat utama dari shell scripting adalah untuk otomatisasi tugas-tugas administratif sistem yang repetitif, manajemen berkas, hingga konfigurasi server, sehingga meningkatkan efisiensi kerja seorang administrator sistem atau pengembang perangkat lunak.<br>

Sebuah berkas script Bash dimulai dengan baris deklarasi khusus yang disebut Shebang (misalnya #!/bin/bash) pada baris pertama untuk memberi tahu kernel interpreter mana yang harus digunakan untuk mengeksekusi kode di dalamnya. Di dalam lingkungan Bash, kita dapat memanfaatkan berbagai fitur pemrograman standar seperti variabel, operasi aritmetika, pengondisian (if-else), serta perulangan (for dan while). Agar sebuah berkas script dapat dijalankan langsung melalui terminal menggunakan perintah ./nama_file.sh, hak akses berkas tersebut harus diubah terlebih dahulu menggunakan perintah chmod +x untuk memberikan izin eksekusi (executable permission).<br>

## Guided

### 1. Permulaan (Otomatisasi Informasi Sistem)
Pada tugas pertama, berkas greeting.sh dibuat untuk mengotomatiskan penampilan informasi dasar sistem.<br>
- Mekanisme: Script ini menggunakan perintah internal Linux seperti date untuk mengambil waktu dan tanggal saat ini, serta perintah who untuk mendaftar seluruh sesi user yang sedang aktif masuk ke dalam sistem. Ketika dijalankan, Bash akan menyapa pengguna dan langsung mencetak parameter dinamis tersebut ke layar terminal secara instan.<br>

### 2. Pengondisian Menggunakan Elemen Waktu
Tugas kedua pada berkas greeting_1.sh mengimplementasikan logika percabangan berdasarkan parameter eksternal.<br>
- Mekanisme: Script ini mengekstrak angka jam digital saat ini saja menggunakan format date +%k. Nilai jam yang didapat kemudian diuji melalui struktur pengondisian interval (struktur if atau case) untuk menentukan kategori waktu: pagi (05:01-10:00), siang (10:01-15:00), sore (15:01-19:00), atau malam (19:01-05:00). Hasilnya, teks salam yang dicetak akan berubah secara adaptif mengikuti jam riwayat komputer saat script dieksekusi.<br>

### 3. Perulangan Kontrol (Countdown)
Tugas ketiga pada berkas countdown.sh menerapkan struktur kontrol perulangan mundur.<br>  
- Mekanisme: Menggunakan struktur perulangan while atau for, program diatur untuk menginisialisasi variabel pencacah pada angka 10, mencetaknya ke layar, lalu menurunkannya secara bertahap (decrement) sebanyak satu angka pada setiap iterasi. Perulangan akan terus berjalan secara sekuensial hingga mencapai batasan angka 1, lalu keluar dari blok perulangan untuk mencetak kata penutup "GO!".<br> 

### 4. Input Pengguna Secara Interaktif
Tugas keempat pada berkas countdown_1.sh menambahkan fungsionalitas interaksi dinamis antara pengguna dan script.<br>  
- Mekanisme: Program menggunakan perintah Bash read untuk menahan jalannya eksekusi sementara waktu dan menunggu pengguna mengetikkan angka batas awal melalui keyboard. Angka yang dimasukkan tersebut disimpan ke dalam sebuah variabel lokal yang kemudian dijadikan sebagai nilai awal (initial value) untuk menjalankan prosedur perulangan mundur countdown seperti pada soal sebelumnya.<br>  

### 5. Parameter Argumen Script
Tugas kelima pada berkas countdown_2.sh menggunakan mekanisme parameter masukan tanpa melalui dialog interaktif.<br>  
- Mekanisme: Argumen dibaca langsung dari baris perintah saat script dipicu (misalnya angka 4 pada perintah ./countdown_2.sh 4). Nilai tersebut ditangkap oleh variabel khusus $1 (argumen pertama). Program juga memanfaatkan pemeriksaan variabel $# untuk mengetahui jumlah total argumen yang dilewatkan pengguna. Jika pengguna lupa memasukkan argumen, program secara pintar akan memicu penanganan kesalahan (error handling) dengan menampilkan petunjuk penggunaan: penggunaan: countdown_2.sh initial_value.<br>  

### 6. Pengondisian (For Loop Direktori)Penjelasan:
Tugas terakhir pada berkas list_direktori.sh bertujuan untuk melakukan pemindaian isi direktori aktif secara otomatis.<br>
- Mekanisme: Script menggunakan struktur perulangan for yang dikombinasikan dengan simbol wildcard tanda bintang (*). Tanda bintang tersebut menginstruksikan Bash untuk mengumpulkan semua nama objek (berkas dan folder) di lokasi direktori saat ini. Perulangan kemudian membaca array nama berkas tersebut satu demi satu dan mencetaknya ke terminal secara berurutan.<br>
