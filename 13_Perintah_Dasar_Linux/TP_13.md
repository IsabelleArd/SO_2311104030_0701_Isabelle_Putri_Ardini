## Dasar Teori
Linux merupakan sistem operasi bertipe Unix yang bersifat open-source dan berbasis multi-user serta multi-tasking. Salah satu cara utama dan paling efisien untuk berinteraksi dengan sistem operasi Linux adalah melalui Command Line Interface (CLI) atau terminal. Terminal membaca instruksi teks yang diketikkan oleh pengguna dan meneruskannya ke shell untuk dieksekusi. Setiap kali terminal dibuka, pengguna akan disambut oleh command prompt yang menyediakan informasi penting mengenai identitas pengguna (username), nama mesin (hostname), serta direktori aktif (working directory).<br>

## Guided

### 1. Analisis Command Prompt Terminal
Bagian pertama dari modul ini meminta praktikan untuk mengamati struktur command prompt yang muncul saat terminal Linux dibuka pertama kali.
- Struktur Umum: Format default pada distribusi populer seperti Ubuntu adalah username@hostname:working_directory$.<br>
- Analisis Identitas: Tanda teks sebelum simbol @ menunjukkan nama pengguna yang sedang aktif, sementara teks setelah @ dan sebelum titik dua (:) merupakan nama mesin virtual atau komputer. Simbol tilde (~) menandakan posisi direktori saat ini berada di Home Directory.<br>
- Hak Akses: Karakter terakhir berupa tanda dollar ($) memberikan informasi penting bahwa pengguna tersebut adalah regular user (user biasa). Jika hak akses beralih menjadi administrator utama (root), karakter tersebut otomatis akan berubah menjadi tanda pagar (#).<br>

### 2. Anatomi Perintah Linux & Kompilasi GCC
Bagian kedua membahas cara mengeksekusi perintah dasar seperti ls (list) untuk melihat isi direktori, baik tanpa argumen maupun dengan memanipulasi option (seperti -al untuk menampilkan seluruh berkas termasuk yang tersembunyi secara detail). Selanjutnya, praktikan melakukan pemrograman C tingkat dasar langsung di lingkungan Linux.<br>
- Mekanisme Kompilasi: Setelah berkas kode sumber bahasa C dibuat (misalnya 2_1.c dan 2_2.c), proses kompilasi tidak lagi menggunakan IDE grafis, melainkan menggunakan utilitas perintah gcc.<br>
- Sintaksis GCC: Perintah kompilasi yang dijalankan menggunakan parameter -o untuk menentukan nama keluaran secara spesifik, dengan format: gcc nama_file.c -o nama_output. Melalui opsi ini, hasil kompilasi akan menghasilkan berkas biner eksekutabel sesuai nama yang diinginkan (bukan nama default a.out).<br>
- Eksekusi Program: Berkas biner yang telah berhasil dibuat kemudian dieksekusi melalui terminal dengan mengetikkan simbol ./nama_output. Penggunaan tanda ./ (dot-slash) sangat krusial di Linux untuk menginstruksikan shell agar mencari dan menjalankan berkas eksekutabel yang berada tepat di dalam direktori aktif saat ini.<br>
